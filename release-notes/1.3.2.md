# TPS Finances 1.3.2

Fixes iPad/iPhone activation: previous releases marked the whole plugin desktop-only and imported the desktop HTTP callback server during startup. The plugin now supports mobile, with Node/Electron loaded only when desktop Plaid Link is explicitly opened.

- Use synced accounts, transactions, holdings, budgets, manual cash, and resale assets on mobile.
- Connect/Reconnect controls explain the desktop handoff and are disabled on mobile. Commands and direct calls reject before requesting provider tokens or loading desktop dependencies.
- Correct the dashboard's credential setup guidance to point to TPS Controller; account/transaction storage, settings, and device-local tokens are unchanged.

This is a patch for platform activation. Minimum Obsidian version remains **1.12.0** (Controller Plaid operations require Controller 1.3.0+ and Obsidian 1.12.3+). Bank connection/reconnection remains desktop-only. Sync the resulting notes with your vault; desktop Plaid tokens do not move to mobile.

Validation: **120 tests passed**, full TypeScript check/build, and a mandatory separate final production build deployed to Obsidian Plugin Test Vault. All six mobile loading/Link tests also passed against the exact final main.js. Those checks run without Node, Electron, Buffer, or process and cover manual cash-account/transaction writes and the resulting balance. Mobile-emulation UI verification covered the dashboard, all four settings destinations, disabled Connect/Reconnect, and opening/cancelling the cash-account form. Desktop mode was restored and the final plugin reloaded; desktop connection controls remained available. No provider request was made. Runtime data.json remained byte-identical.

Physical iPad/iPhone verification is pending your device test. No production vault was inspected or deployed. These tested artifacts are ready for your manual BRAT pull of **1.3.2**; the tag is numeric and this release is not a production installation claim.
