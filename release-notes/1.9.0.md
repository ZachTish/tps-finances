# 1.9.0 — Finance records here, connections in Controller

- Reduced Finances settings to Data & routing, Rules & budgets, and Properties. Existing record formats, root/folder routing, property migrations, rules, budgets and logging remain.
- Settings and dashboard Connections open Controller → Connections → Banks & Wallet, including on unpaired phones. Quick Sync and existing commands/API IDs remain compatible.
- Moved the existing bank-management editor and transaction-history depth into Controller. Removed the empty Plaid setup tab, duplicate Connections tab and obsolete Wallet-import-toggle instructions.
- Pending actions disable their initiating button. Disconnect still requires confirmation and preserves Markdown records. Manual cash, asset and transaction workflows remain available without Controller.

## Compatibility and state

This minor release adds connection settings ownership/API support without changing note schemas or requiring a settings migration. Minimum Obsidian: **1.12.0**. Install **Controller 2.6.0 first**, then **Finances 1.9.0**, **Health 3.4.0**, and **AI Gateway 0.10.0** through BRAT. Controller requires Obsidian 1.12.3 on each device.

Controller owns visible connection navigation and lifecycle; each domain plugin supplies its existing editor and validated saves/operations through `api.connectionSettings = { version: 1, render(parent): dispose }`. This does not duplicate or relocate provider execution, credentials, pairing authority, tokens, cursors, requests or note mappings. Navigation state is transient. Existing commands and service APIs remain. Bank/AI configuration and actual secret values remain device-local; Health's USDA reference names remain shared vault settings.

Apple Wallet permission, vault/account selection and initial import happen in TishOS on the iPhone. The existing native Wallet setup requires TishOS 0.18.2 (152) or newer. This release does not change native authorization, start a connection, grant permission, or enable background automation merely by opening settings.
