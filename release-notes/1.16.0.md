# TPS Finances 1.16.0 — Browse transaction history from Overview

Overview now labels its capped list **Latest 80 transactions** and provides **Browse all transactions** above it. The button opens the existing configured Transactions Base in a new tab. In Atomic notes mode it selects `Transactions (Atomic notes).base` when that Base exists, with the existing `Transactions.base` fallback; Atomic line mode uses `Transactions.base`. The Overview still renders at most 80 rows. The browse button keeps its visible label, wrapping text, and a 44 px touch target on narrow panels.

This backward-compatible feature changes no transaction notes, discovery mode, settings, visibility policy, Home summary, or plugin API contract. No migration is needed. Minimum Obsidian remains **1.12.0**. Overview still builds the full dashboard model before displaying recent rows; browsing uses the existing Base and does not itself scan or read transactions. If the configured Transactions Base is absent, the existing action error is shown instead of opening a tab. The existing Base shows opaque transaction filenames; that presentation is unchanged. Physical iPhone layout remains unverified.
