# TPS Finances 0.4.2

## Release intent

This is the initial private GitHub release package for installing and updating the existing TPS Finances `0.4.2` build with BRAT. Packaging it for BRAT does not change runtime behavior. The release must attach the already-tested `main.js`, `manifest.json`, and `styles.css` artifacts.

## Compatibility

- Minimum Obsidian version: `1.12.0`.
- Desktop only, as declared by `manifest.json`.
- Private-repository BRAT installs require a fine-grained GitHub token scoped to `ZachTish/tps-finances` with **Contents: Read-only**; the token must never be committed.

## Validation

- `npm test`: passed `15/15` tests, including contract/storage, atomic transaction movement, modal safety, credential handling, and mocked Plaid synchronization coverage.
- Separate `npm run build`: passed TypeScript checking and the production esbuild bundle.
- Test-vault deployment: `[runtime-deploy] target=test ... unchanged`; all three runtime artifacts are byte-identical to the built source artifacts.
- No production deployment or reload was performed. This package remains test-vault-only until an explicitly authorized promotion.

## Known limitations

- Plaid authentication and synchronization require the desktop app and device-local SecretStorage configuration.
- Provider-facing Plaid flows were not called during this packaging pass; the declared suite uses mocked provider responses.
- Because the repository is private, each BRAT installation must retain valid read-only GitHub authentication on that device.
