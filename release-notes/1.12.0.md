# TPS Finances 1.12.0 — Hide dashboard amounts

The main **Overview** dashboard has an eye button to hide financial values. Tap each masked value to reveal it individually, then tap again to conceal it. Summary totals, account balances, share quantities, investment prices/values and transaction amounts are covered. Percentages, dates and labels stay visible. **Show amounts** restores them all.

This affects only Overview. Budget, home summaries, notes, Bases and forms keep their existing display. The choice is temporary for each open dashboard; refreshes and returning to Overview remask individual reveals, while closing/reopening the dashboard or reloading the plugin resets to visible. No persisted settings or migration.

The eye sits beside the title, and the controls use native accessible buttons with 44 px touch targets. Masked values are not included in text, tooltips or accessible labels. Reveal clicks and Enter/Space do not open transaction notes. Toggling reuses the already-loaded model and reveals update only their button, with no extra data reads or writes.

Minor release for an additive feature. Minimum Obsidian: **1.12.0**. Tested in **Obsidian Plugin Test Vault**, ready for the user’s BRAT pull. Physical iPhone behavior requires device acceptance. Production has not been modified.
