# TPS Finances 9.0.0 — Native Bases and Canvas dashboards

Removes the custom Finance/Budget views, ribbon, Open finances command, GCM dashboard shortcut, home-summary renderer and dashboard refresh listeners. Finance no longer rebuilds dashboard data after note changes. Calculations, the read-only getDashboardModel compatibility API, manual cash/assets, rules, budgets, reviews and property migrations remain supported.

Open Budgets Base keeps the existing open-budget command ID and opens the configured existing Budgets.base without creating or rewriting it. The new Edit current finance record command and Edit finance record note-menu action retain access to budget, manual asset-value and transaction-classification editors. They use the existing save/conflict owners. Rendering APIs openDashboard and renderHomeSummary are removed; no other active TPS plugin references them.

Includes the retained, previously unpublished 8.0.1 settings simplification: all 57 mappings remain in their five groups, with imported/older fields in one disclosure and no new persisted settings. Duplicate dashboard refresh callbacks are now retired with the views themselves. The historical 8.0.1 receipt remains evidence, not a separate release.

Validation: **276 tests passed, 0 skipped, 0 failures**, plus a separate production build. Actual compiled-plugin regressions cover mobile loading, zero startup/event-burst scans, body reads and writes over 1,000 events, retained command/menu routing, unready classification ownership, model errors, atomic guards, budgets, balances and mapping preservation. Dashboard-only render tests are retired; data/model regressions remain.

Installed acceptance: all three settings destinations and all five property groups inspected; controls, selected-route accessibility, single disclosure depth and narrow layout verified. Created a synthetic budget through the real editor, changed its amount from 125 to 175, and observed the native Base update while its definition remained unchanged. The existing ID and note body were preserved. The new edit command opened that budget editor. Context-menu callback routing, asset and transaction editor routing are covered by compiled-plugin tests. Temporary classification/folder configuration was restored and synthetic fixtures archived. Both data.json and enabled state remain byte-for-byte unchanged.

Minimum Obsidian: **1.12.0**. Major version reflects removal of supported custom dashboard views and launchers. No startup migration, replacement dashboard, watcher or repair is added. Existing notes, authored Bases/Canvas, settings and private state are preserved. Close any saved obsolete dashboard tab and open your own Base or Canvas.

Validation was performed in **Obsidian Plugin Test Vault**, with Sync disabled and normal consumers enabled. The full declared test suite and a separate production build are required for the final artifacts. Final SHA-256 digests are included in the public release; exact local logs and UI receipts are retained outside the vault. Test installation, public release and production installation are distinct. This release is ready for the user's BRAT pull; production was not directly updated. No physical-phone result or performance timing is claimed.
