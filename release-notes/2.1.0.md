# TPS Finances 2.1.0 — Configurable kind-list and scheduled properties

Finances now follows TPS Global Context Menu's configured frontmatterKinds v2 writer for new and updated whole-note accounts, transactions, investments, holdings, snapshots, rules, and budgets. GCM's Scheduled custom-property key controls the date property on new Finance notes. Existing kind/date settings remain as legacy read aliases; the configured primary and aliases keep older notes visible during migration. Shared visible kind paths use the existing Finance type field to identify the internal record type. No classification path is built into Finances.

Generated Finance Bases use the configured GCM classification and Scheduled key. Uncustomized generated Bases can update; custom Bases require a separate review. Missing, disabled, conflicting, or ambiguous mappings stop a write before changing a note. GCM v1 or absent GCM retains the previous Finance behavior for installations not yet using v2. This release does not migrate old notes, change provider records, add an automatic repair scan, or change numeric finance-rule priority. Install GCM 7.0.0 and configure its writer/read aliases before switching Finance notes to the new list model.

This is a backward-compatible **minor** version. Minimum Obsidian remains **1.12.0**. The TishOS v0.2 note and Base migration is a separate coordinated step.
