# TPS Finances 0.4.3

This patch makes settings persistence merge-safe and durable under overlapping edits.

## Changes

- Reloads current plugin data and applies only fields changed by this running instance.
- Preserves synchronized settings and unknown newer-release fields.
- Retains rapid reverts, waits for durable state, and allows a queued newer value to supersede an earlier failed write.
