# TPS Finances 0.4.3

This patch makes settings persistence merge-safe and durable under overlapping edits.

## Changes

- Reloads current plugin data and applies only fields changed by this running instance.
- Preserves synchronized settings and unknown newer-release fields.
- Retains rapid reverts, waits for durable state, and allows a queued newer value to supersede an earlier failed write.

## Compatibility and validation

- Minimum Obsidian: 1.12.0; desktop-only; no manual migration.
- Focused persistence tests and full declared suite: 20/20 passed; TypeScript and diff checks passed.
- A separate production-mode build deployed byte-identical artifacts to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; Finances registered normally and no runtime settings file was created or replaced.
- Live Plaid calls remain outside this regression pass; provider behavior is covered with mocks.
