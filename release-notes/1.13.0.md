# TPS Finances 1.13.0 — Clearer phone dashboard

First opening Finances now shows a loading status until the model is ready. Recent transaction rows wrap on narrow screens, reveal the imported source name on touch layouts, and keep that name in the row's accessible label. Narrow account, route, budget, and classify controls have 44 px touch targets. Subsequent refreshes keep the prior dashboard visible. The Overview amount-privacy control is unchanged.

This is an additive mobile UX release with no note or settings migration, extra data read, background task, or finance-data change. Minimum Obsidian: **1.12.0**. Tested in **Obsidian Plugin Test Vault** for the user's BRAT pull; production has not been modified.
