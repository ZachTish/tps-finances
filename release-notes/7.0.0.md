# TPS Finances 7.0.0 — Lean finance note output

New manual finance notes stop writing duplicate account names/foreign IDs, pending:false and blank optional fields. Manual accounts and dashboard labels use the shared configured title; old provider account names remain searchable. Manual asset creation omits empty relationship fields. Account labels avoid appending a mask already present in the chosen title. Explicit title review no longer adds providerName/providerTitle bookkeeping.

Transactions now save manual categories through the existing configurable category property shared with rules and budgets. Older categoryOverride/providerCategory fields remain readable. Explicit category edits remove the selected note's legacy override; the existing identity, concurrent-edit and exclusion guards remain. All property names stay configurable. Common in Properties now contains the existing category control; no persisted setting/action is added or removed, and navigation/mobile behavior is unchanged.

This is intentionally major: external consumers expecting financeAccountId/accountName/categoryOverride or provider title metadata on newly created records must adopt the lean format. Configure the existing Common category mapping for custom output names. Existing notes are not rewritten by installation. TishOS app imports remain outside this plugin; its private mapping/title-baseline adoption must precede removal of app-dependent fields from production notes. The unused provider-upsert branch and merge/compaction helpers are deleted. Holdings resolve the existing account wikilink through the same account map as snapshots, retaining legacy reads only for older holdings without a link. No new background service, state store, scheduler, watcher or repair loop is introduced. Requires Obsidian **1.12.0**.
