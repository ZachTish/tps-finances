# TPS Finances 2.1.2 — Preserve explicitly configured field names

Finances now retains a field name saved explicitly in Properties even when it equals that field's default. The per-field toggle pins the current name or resets it to the default. Pin-only saves update settings without scanning or rewriting notes or Bases. Effective Finance note fields stay the same; actual renames continue through the existing preview and confirmed migration. This provides one settings-owned field map for external writers such as the TishOS Companion Wallet importer.

This is a backward-compatible **patch**. Existing sparse mappings remain valid in Finances. The coordinated TishOS v0.2 migration will explicitly pin the 14 Finance fields emitted by Wallet; Companion 0.22.4 requires that complete map before writing. Kind classifications and the Scheduled, title, and record identity keys remain configured in GCM. Minimum Obsidian version remains **1.12.0**.

## Validation

- `npm test`: 2 connection tests and 377 Finance tests passed; TypeScript validation and the production bundle build passed.
- The final, separate `npm run build` deployed the byte-checked artifacts to Obsidian Plugin Test Vault. With the plugin loaded, its Properties screen showed the new per-field explicit-name toggle; the toggle was checked and unchecked without saving a real setting.
- No provider import or production-vault installation was performed as part of this release.
