# TPS Finances 2.1.1 — Read and update legacy investments safely

Finance now recognizes an older investment transaction whose Finance `type` is investment but whose legacy tag belonged to ordinary transactions, provided GCM maps both to the same configured kind-list value. A direct Finance update writes that list, retires the old classification tag through GCM 7.0.1, and folds an old Finance date into the configured Scheduled key. Manual tags and unrelated fields remain. Differing configured paths and conflicting authored kind fields fail closed, including case variants of the list key. No background repair, startup scan, or new Finance taxonomy setting is added.

This is a backward-compatible **patch** with no saved-settings or identity change. Minimum Obsidian remains **1.12.0**. Install GCM 7.0.1 and configure its shared transaction mappings before updating these records. The one-time TishOS v0.2 note and Base migration is a separate coordinated step.
