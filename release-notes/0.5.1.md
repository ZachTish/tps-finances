# TPS Finances 0.5.1

This patch makes monthly budget calculation scale with the number of transactions plus budgets instead of multiplying both collections.

## Changes

- Aggregates eligible current-month spending into normalized categories in one transaction pass.
- Reuses each category total for budgets that resolve to that category, including duplicate-category budgets.
- Preserves budget order, local-month prefix behavior, category normalization, eligible transaction types/subtypes, negative-zero results, settings, and persisted finance data.

## Compatibility and validation

- Minimum Obsidian: 1.12.0; desktop-only; no settings or data migration.
- Full declared suite: 23/23 passed, including legacy-result equivalence and a one-traversal instrumentation check.
- An independent 20,000-case randomized comparison found no production-contract differences.
- A synthetic 120-budget/30,000-transaction benchmark measured about 359 ms for the prior calculation and 2.5 ms for the new calculation.
- The final production-mode build deployed only to the isolated test vault.
- Obsidian 1.12.7 was reloaded with **Reload app without saving**; all Finances commands registered and the disconnected dashboard rendered normally without connecting Plaid, syncing, or writing runtime state.
- Live Plaid calls and a populated personal finance dashboard remain outside this pass; provider behavior is covered by mocks and budget results by the equivalence oracle.
