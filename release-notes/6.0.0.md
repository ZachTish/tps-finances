# TPS Finances 6.0.0 — keep manual finance, remove import execution

Bank and Wallet importing, Plaid linking/clients, Controller import integration, import commands, and device-secret startup loading are removed. Dashboard Sync/connection controls are gone. Manual accounts, cash transactions, asset valuations, budgets, categorization, title review, and existing-note dashboards remain.

This major release intentionally stops plugin imports. It does not configure or verify a TishOS replacement. Existing notes, identities, credentials, provider mappings, connections, and operational state are preserved. The connection-settings compatibility API reports retirement without accessing providers or private state.

## Reduction and ownership

- Eight provider/transport modules plus the unused transaction-content writer removed.
- One layout-ready folder/Base creation owner and two import commands removed. No replacement timer, scheduler, polling loop, cache, or repair framework.
- Removed provider account/holding/transaction writers, generated snapshot writer, inline writers/rerouting, and scans used only by those paths.
- Runtime source: 23 added / 2,078 removed, net reduction **2,055 lines**, excluding tests/docs/generated bundles.
- Dashboard metadata invalidation and read-only inventories remain. Explicit whole-note migration retains bounded legacy reads and identity/conflict protection. Existing Bases are not rewritten merely by opening the dashboard.

## Validation

- **336 tests passed**, no failures or skips; TypeScript and separate final build passed.
- Tests cover zero generated-file writes on activation and 20 model reads; existing user-authored Base content is preserved. Forty compatibility-panel opens perform no provider/state/timer/vault work. Mocked boundaries are declared in the tests.
- Installed Mac test-vault UI created a $100 wallet, recorded a $12.50 expense, and showed $87.50 cash. A $200 asset edited to $180 changed net worth from $287.50 to $267.50. Incomplete classification was rejected while preserving form inputs.
- Repeated cash creation/logging after final 6.0.0 deployment and manifest/plugin reload: two Markdown records with configured `id` and `kind`, correct $87.50 balance, no generated Base. Settings restored and fixtures archived.
- Suite-wide foreground measurements (five each), not Finance-only attribution: startup median 6084.7 ms versus 6066.2 ms; 20-note navigation median 838.9 ms versus 897.2 ms. Idle, typing, Sync-burst, settings and Finance-opening checks observed no TPS maintenance/generated-file writes. Core saves/indexing counted separately. No production-speed claim.

Requires **Obsidian 1.12.0+**. Physical iPhone acceptance remains unverified. Tested in Obsidian Plugin Test Vault and ready for the user's BRAT pull; production is unchanged. Other plugins' cleanup and import owners are separate releases—this artifact does not disable a different plugin's independently configured importer.

Downgrading can restore prior import execution against preserved settings and connections. Review those controls before enabling an older version. Installation does not roll back or rewrite notes.
